# Sonora

A generative musical field. Particles drift on a seeded flow, then lock into the real shape of the notes you play — sine, square, triangle, or saw.

## Run

```bash
npm install
npm run dev
```

Tap once to unlock audio. **Side** is the particle waveform. **Top** is the same tone as a 3D plate, so chords read as a pattern from above. **Both** shows the two together. Play the on-screen piano or the computer keys (A–L, Z/X to shift octave). **Stabilize** freezes the silhouette and turns it into a new tone. **Hide** drops the studio so only the field is left. Export saves a PNG of the canvas.
