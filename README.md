# Sonora

A generative musical field. Particles drift on a seeded flow, then lock into the real shape of the notes you play — sine, square, triangle, or saw.

## Run

```bash
npm install
npm run dev
```

Tap once to unlock audio. The top view is sand on a metal plate. Set a frequency from 0.01 Hz to 100 THz. Audible tones draw a real Chladni figure and play. 74 THz is infrared light — the sand only shimmers, unless you ask for the scaled figure. Play the on-screen piano or the computer keys (A–L, Z/X to shift octave). **Stabilize** freezes the silhouette and turns it into a new tone. **Hide** drops the studio so only the field is left. Export saves a PNG of the canvas.
